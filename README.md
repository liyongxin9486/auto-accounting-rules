# 自动记账规则一键安装包

[自动记账](https://github.com/AutoAccountingOrg/AutoAccounting)（AutoAccounting）的**离线规则包 + 一键合并安装器**：把一套完整的 183 条支付通知识别规则（微信、支付宝、银行短信/公众号通知等）及公共解析/分类脚本，通过手机本地接口安全合并进已装好的自动记账，无需手动逐条导入。

**规则包版本：2026.11.03**（原有 163 条系统规则 + 20 条补充规则，共 183 条，其中 182 条启用）

## 包内容

| 文件 | 说明 |
| --- | --- |
| `一键安装自动记账规则.sh` | 一键合并安装器（root shell 脚本） |
| `自动记账完整规则包.zip` | 规则数据包（安装器会先做 SHA256 校验） |
| `rules.json` | 183 条规则的明文源（可直接阅读/审计） |
| `common.js` / `category.js` | 公共解析脚本 / 分类脚本（明文源） |
| `manifest.json` | 包清单（版本、条数、禁用规则） |
| `使用说明.txt` | 详细用法（检查模式、更新模式、备份路径） |
| `先看这里-手机安装步骤.txt` | 手机端快速安装步骤 |
| `安装器验证记录.json` | 本机验证结果（重复运行、幂等、冲突停止等） |
| `文件校验清单.json` | 各文件 SHA256 清单 |

> 规则包**不包含**账单流水、账号、资产、API 密钥或 LSPosed 作用域配置，不修改 OCR 设置。

## 环境依赖

- **root**（Magisk 等均可）
- 已安装并正常工作的**自动记账**（本机验证版本：4.0.2 Canary）+ LSPosed 正常运行
- 自动记账本地服务端口 **52045**（脚本只访问 `127.0.0.1`，不联网下载规则、不上传任何数据）
- Android 系统自带命令：`curl`、`sqlite3`、`unzip`、`sha256sum`、`mktemp`

## 安装步骤

1. 把 `一键安装自动记账规则.sh` 和 `自动记账完整规则包.zip` **一起**复制到手机内部存储根目录 `/sdcard`（两者必须同目录，**不要解压 ZIP**）
2. 确认自动记账与 LSPosed 正常工作（主页显示"工作中"）
3. 用支持 Root 执行的文件管理器运行 `.sh` 并授权；或在手机终端执行：

   ```bash
   su -c 'sh /sdcard/一键安装自动记账规则.sh'
   ```

> 普通文件管理器不一定支持执行 `.sh`，用手机终端跑上面的命令即可。脚本路径不要包含引号等 shell 特殊字符。

## 三种运行模式

| 命令 | 作用 |
| --- | --- |
| `sh 一键安装自动记账规则.sh`（默认） | **先备份再合并**：只添加手机上缺少的规则；已有规则不重复添加、内容不同的保留并提示，不覆盖后来的更新或个人修改 |
| `... --check` | **仅检查**：完整走一遍校验、引擎验证和差异比对，不修改任何规则或脚本 |
| `... --update` | **明确更新**：用包内代码更新同名规则（仍保留手机上已有的启用/自动提交开关） |

安全机制：

- 安装前校验 ZIP 的 SHA256、规则 JSON 结构、条数与清单一致性、包内重复与解析器名冲突，任一失败即停止（未写入任何内容）
- 写入前先用手机端 QuickJS 引擎试运行全部规则，引擎不兼容直接中止
- 安装后读回核对，发现缺失/重复/内容不一致立即报错
- 每次安装自动备份到 `/sdcard/自动记账规则备份/日期时间_进程号/`（安装前/后规则、原公共脚本、安装日志；不含账单）
- 不删除其他规则、不改已有规则的开关、不重跑历史账单、不触发测试账单、不需要重启

## 规则概况

- 覆盖微信、支付宝、各银行 App 通知/短信/公众号等常用支付场景的识别规则
- 规则源（`rules.json` 与两个 JS）完全可读，可自行审计后安装
- 已知禁用：建行微信公众号新模板兼容（1 条，其余 182 条启用）
- 本机已验证：183 条完整、内容差异 0 条、重复运行幂等（第二次运行新增 0 条）

## 迁移说明

本包只迁移**规则**。换手机时，root、LSPosed 作用域、通知采集、记账软件本身仍需在目标设备单独配置。无法保证其他自动记账版本的本地接口兼容；接口不兼容时脚本会在写入前停止。
